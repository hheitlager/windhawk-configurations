# Emberveil — Windhawk Configurations

A collection of personal Windhawk configuration presets for customizing the Windows desktop.

Part of the [Emberveil](https://github.com/hheitlager/emberveil) project.

## Configuration Collection

|Windhawk Mod|Description|
|---|---|
|Taskbar Clock Customization|Emberveil-inspired taskbar clock styling|
|Mawaqit|Personal configuration for the Mawaqit prayer clock|
|Windows 11 Notification Center Styler|Emberveil and Catppuccin-inspired notification center designs|
|Windows 11 Start Menu Styler|Custom Start menu layouts and visual styling|
|Windows 11 Taskbar Styler|Taskbar styling presets, including custom icons|

Each directory contains the relevant JSON configuration files and any included supporting assets.

## Installation

1. Install [Windhawk](https://windhawk.net/).
    
2. Install the corresponding Windhawk mod.
    
3. Open the mod's settings page.
    
4. Import or apply the configuration using the method supported by that mod.
    
5. Review any settings specific to your Windows installation.
    

Some presets contain absolute paths to custom image assets. Update those paths to match your local installation.

## Themes

The collection currently includes configurations inspired by:

- **Emberveil** — dark desktop styling with warm gold accents.
    
- **Catppuccin** — softer color palettes and desktop styling inspired by the Catppuccin theme family.
    

Some configurations represent alternative designs or earlier iterations. Not every preset is intended to be used simultaneously.

## Compatibility

These configurations were developed for a customized Windows 11 environment.

Appearance and functionality may vary depending on your Windows version, Windhawk version, installed mods, display scaling, and other desktop customizations.
